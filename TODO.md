# TODO — MCNuX build plan

Re-verified plan (commit 94553f9, plan cycle 2026-08-27; all 13 research slices independently confirmed the prior tier structure — no checked item was stale, no tracked item secretly done). Current state: every pure-function layer — RNG, units, stats machinery, tetrad, opacity/coefficients/table-range, geodesic math, ledger arithmetic + closure diagnostic, TRP relabel map, emission/interaction/fluid-gather pure functions — is complete, static_assert-covered, and mirrored in the 140-row selftest battery with committed goldens; the runtime emission/creation loop (emit-core) and ledger-closure diagnostic are live. What is missing is the rest of the runtime physics pipeline: nothing samples/applies interaction episodes, no packet is ever absorbed or removed, boundary-exiting packets are silently dropped, `opacity_source="table"` is a dead runtime path, and ~17 of the ~23 spec-pinned benchmarks do not exist. Every task below is greenfield wiring/test-authoring on finished building blocks; none is a bug fix.

## Standing facts every item inherits

- **Fluid-gather reuse (C1):** the gather/tile-walk helpers live in the shared header `mcnux_gather.hxx`: `require_driver`, `MetricGroups`/`metric_groups()`, `HydroGroups`/`hydro_groups()`, `make_gather`/`make_fluid_gather` (int-box + PacketIter overloads), `for_each_packet_tile[_raw]`, shared `fill_packet_diag`. Reuse from there, never duplicate.
- **Atomic deposition idiom (C2):** the [MCNX-GPU-02] idiom is built ONCE in `mcnux_deposit.hxx` (`SourceGroups`/`source_groups()`, `SourceViews`, `deposit_delta()` = `source_from_delta` + five `Gpu::Atomic::AddNoRet`), first production consumer `mcnux_emission.cxx`. `episode-driver` and `absorb-remove` reuse it with `scattering_delta`/`absorption_delta` (`mcnux_srcterms.hxx:62-87`).
- **Ledger discipline (all new event paths):** feed audits from pre-negation `LedgerDelta`s, never from post-negation `SourceContribution` (self-cancels); the closure multiply must use the same ΔV·Δt the deposit divided by. The `MCNuX_LedgerClosure` grid reduction is rank-local and unigrid-only (commented, per `fill_packet_diag` precedent) — `interactions-fixedseed`/`ownership-multibox` need a rank reduction + level masking.
- **Per-packet RNG keying:** event paths key the counter-based RNG on `packet_rng_key(id,cpu)=(cpu<<39)|id` (`mcnux_emission.hxx`, static_assert-pinned bit-63-clear + cell-key disjointness), NOT raw idcpu. Ids come from `SetParticleIDandCPU(NextID-reserved id, MyProc())`; synthetic-fixture ids 1..8 bypass NextID (paramcheck-guarded against `enable_emission`).
- **Selftest growth:** the index→name row table in `mcnux_selftest.cxx` is APPEND-ONLY; new checks go in per-domain `mcnux_selftest_<domain>.cxx` files with appenders declared in `mcnux_selftest.hxx`. The battery is exactly full (rows 0..SIZE−1; SIZE=140 as of emit-bins) — appending rows means bumping `interface.ccl` SIZE to the new count in the same change and re-capturing the `unit-selftest` golden TSV. Every new shared header gets `#include`d from `stub.cxx`.
- **Coefficient access:** always via `RangedTableCoefficients`/the analytic dispatch in `mcnux_coefficients.hxx`, never bare `BaselineTableCoefficients`.
- **Old task-id breadcrumbs in code comments** (`T21b` in `mcnux_trp.hxx:36-41`, `T23` in `mcnux_geodesic.cxx` boundary comment, `T25d` in `mcnux_rng.hxx:35-40`, plus old T14a/T18a/T33 commit prefixes) refer to the discarded pre-reset numbering, NOT this plan. Mapping: T21b→`trp-alpha`, T23→`escape-tallies`, T25d→documented RNG host-vs-device GPU deferral (tracked, not planned — sandbox has no GPU path; GPU compile checks are CI-only by design).
- Benchmarks whose acceptance is subjective/statistical use the repo's sanctioned 4σ pattern (`mcnux_stats.hxx`: pinned N_p=2^20, seed 1296518744, bound 4.0, non-strict ≤); sigma must be analytically propagated/documented, never computed by `mcnux_stats.hxx`.
