- **Fluid-gather reuse (C1):** the gather/tile-walk helpers live in the shared header `mcnux_gather.hxx`: `require_driver`, `MetricGroups`/`metric_groups()`, `HydroGroups`/`hydro_groups()`, `make_gather`/`make_fluid_gather` (int-box + PacketIter overloads), `for_each_packet_tile[_raw]`, shared `fill_packet_diag`. - **Atomic deposition idiom (C2):** the [MCNX-GPU-02] idiom is built ONCE in `mcnux_deposit.hxx` (`SourceGroups`/`source_groups()`, `SourceViews`, `deposit_delta()` = `source_from_delta` + five `Gpu::Atomic::AddNoRet`); production consumers are `mcnux_emission.cxx` and `mcnux_interactions.cxx` (`scattering_delta`/`absorption_delta`, `mcnux_srcterms.hxx:62-87`).

The `MCNuX_LedgerClosure` grid reduction is rank-local and unigrid-only (commented, per `fill_packet_diag` precedent) — acceptable at NPROCS 1/unigrid; rank reduction + level masking belongs to ownership-multibox.
- **Per-packet RNG keying:** event paths key the counter-based RNG on `packet_rng_key(id,cpu)=(cpu<<39)|id` (`mcnux_emission.hxx`, static_assert-pinned bit-63-clear + cell-key disjointness), NOT raw idcpu. - **Selftest growth:** the index→name row table in `mcnux_selftest.cxx` is APPEND-ONLY; new checks go in per-domain `mcnux_selftest_<domain>.cxx` files with appenders declared in `mcnux_selftest.hxx`. - **Old task-id breadcrumbs in code comments** (`T21b` in `mcnux_trp.hxx:36-41`, `T23` in `mcnux_geodesic.cxx` boundary comment, `T25d` in `mcnux_rng.hxx:35-40`, plus old T14a/T18a/T33 commit prefixes) refer to the discarded pre-reset numbering, NOT this plan.
